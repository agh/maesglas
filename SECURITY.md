# Security

Only the latest release receives best-effort security fixes.

Do not report vulnerabilities in public issues or attach sensitive
configuration. A private reporting channel must be enabled and verified before
the first release. This repository does not yet direct reporters to an
unverified channel.

Handling is best effort, without response deadlines, service levels, or
bounties. An advisory follows a released fix. Vulnerabilities in other projects
belong in those projects' private reporting channels.
