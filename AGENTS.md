# Repository instructions

The authored identity is `identity/maesglas.json`. Generated artifacts are
listed in `identity/generated.json`; change their source, then run
`python3 scripts/generate.py`. A stale artifact fails the gate.

Read `docs/design.md`, `docs/ports.md`, and `CONTRIBUTING.md` before changing
the system. Preserve the light default and complete dark companion. Every text
role, including all ANSI slots, must clear 4.5:1 on every content ground.
Essential boundaries must clear 3:1. Do not exempt a failing pair.

Use the pinned checks and run `scripts/gate.sh`. Application configuration and
caches belong in disposable directories during validation. Never install a theme
into a person's configuration as a test.

Public examples are synthetic. Do not add machine identifiers, personal paths,
session material, or authorship trailers naming tools. Do not copy private
configuration into this repository.

Write US English. Keep claims about other products dated and versioned;
unverified compatibility stays out of the README and release notes. Preserve
upstream license notices.

Do not commit or publish without the owner's instruction. Any requested commit
must be signed and carry the sign-off in `CONTRIBUTING.md`.
